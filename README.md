# Netflix-bilingual-subtitles-on-Mac-Safari
一個好用的Netflix雙語字幕
(文件在user.js)
使用方法如下:
1.去app store下载userscripts

![uA1ggDp9x5JcmxVFqGrhGUXXq628YYHl.png](https://cdn.nodeimage.com/i/uA1ggDp9x5JcmxVFqGrhGUXXq628YYHl.png)

2.启用之后点击底部的

![Y8g9ng7nymmIXGdfJUIDHOZzbsoVhLgy.png](https://cdn.nodeimage.com/i/Y8g9ng7nymmIXGdfJUIDHOZzbsoVhLgy.png)

3.左边右上角创建一个新的脚本

![qOVMO4bekOAyuzjIdbC6RVQXwO7r1Tq5.png](https://cdn.nodeimage.com/i/qOVMO4bekOAyuzjIdbC6RVQXwO7r1Tq5.png)

4.复制整个user.js到右边框框保存即可
打开你要看的影片之后打开netflix的字幕点一下英文点一下中文，这样他就会抓到字幕数据就可正常使用
所有的参数都可调整，要用简体中文的改成zh_CN就行
